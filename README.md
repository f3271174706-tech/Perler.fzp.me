# 智能拼豆板

手机优先、零依赖的智能拼豆板原型。高清图纸与颜色分析都保留在浏览器本地。

## 本机启动

在 PowerShell 中运行：

```powershell
.\start-local.ps1
```

然后打开 <http://127.0.0.1:4173/>。按 `Ctrl+C` 停止服务。

## 当前功能

- 导入并完整显示高清 PNG、JPG、WEBP 图纸，不重新生成网格
- 按原图 1:1 像素建立高清画布，仅通过界面缩放适配屏幕，不压缩工作图
- 自动识别规则图纸网格，并按格内主体底色匹配真实 MARD 221 色号
- 使用权威 221 色数据库，显示常备色标记、格数，并支持搜索和多选
- 所选色号保持原亮度，其余豆格降低约 80% 可见度；网格线与编号保持清晰
- 画布先按图纸宽高比和屏幕宽度自适应，完整图纸定义为 100%；可在该自适应画布内缩放、拖动、镜像，缩放下限为 75%
- 拖动带有边界约束：缩小时图纸不能离开画布，放大时画布不会露出图纸外的空白区域
- 手机与桌面响应式界面、明暗主题

> 当图纸网格线不规则、透视变形或被装饰遮挡时，应用会自动退回 MARD 色块识别模式。
